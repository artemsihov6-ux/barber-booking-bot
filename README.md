# 💈 Barber Booking Bot

Бот онлайн-записи для барбершопа, салона или любого мастера. Работает в Telegram и в MAX:
можно запустить один мессенджер или оба сразу, расписание и база у них общие.
Python 3.11+, aiogram 3, maxapi, SQLite.

## Возможности

**Для клиента**
- Запись в пару нажатий: услуга → день → время → имя → телефон → подтверждение
- Показывает только реально свободные окна с учётом длительности услуг
- Номер телефона одной кнопкой («Отправить мой номер»)
- Автонапоминание за 2 часа до визита
- «Мои записи» с отменой
- Прайс и контакты

**Для мастера (админа)**
- Мгновенные уведомления о новых записях и отменах
- `/admin`: список предстоящих записей с именами и телефонами, отмена в один клик (клиент получает уведомление)

## Telegram и MAX

`python bot.py` запускает ботов тех мессенджеров, для которых в `.env` задан токен:

| Мессенджер | Токен | Админы |
|---|---|---|
| Telegram | `BOT_TOKEN` (от @BotFather) | `ADMIN_IDS` |
| MAX | `MAX_BOT_TOKEN` (платформа «MAX для партнёров» → «Чат-боты») | `MAX_ADMIN_IDS` |

Свой ID в каждом мессенджере подскажет команда `/id`.

- Окно, занятое в одном мессенджере, сразу пропадает в другом: двойной записи не будет.
- Админ видит в `/admin` записи из обоих мессенджеров и может отменить любую.
  Клиент получит уведомление там, где записывался.
- Уведомления о новых записях приходят админам во все запущенные мессенджеры.
- В MAX нет нижней клавиатуры, поэтому меню сделано inline-кнопками под сообщением.

Создать бота в MAX могут юрлица, ИП и самозанятые: токен выдаётся после модерации
([инструкция](https://dev.max.ru/docs/chatbots/bots-create)).

## Структура

- `bot.py` — точка входа, запуск Telegram-бота
- `handlers/`, `keyboards.py` — хендлеры и клавиатуры Telegram
- `max_bot/` — запуск, хендлеры и клавиатуры MAX
- `booking.py`, `slots.py`, `db.py`, `notify.py`, `reminders.py`, `views.py` — общая логика:
  запись и отмена, свободные окна, база, уведомления, напоминания, тексты
- `config.py` — услуги, цены, расписание, контакты
